# Mockups

22 telas, desenhadas no Claude Design. Duas formas do mesmo conteúdo:

| Arquivo | Para quem | Observação |
| --- | --- | --- |
| `telas.md` | **IA** | 13 KB: telas, elementos e anotações de comportamento |
| `mockups.html` | humano | 1,9 MB: abra no navegador para ver o layout renderizado |

Leia o `telas.md`. O `.html` é quase todo bundle JavaScript e não renderiza para quem
só lê a marcação — abrir ele em contexto gasta muito e entrega pouco.

O cromo dos mockups é neutro de propósito: cores, bordas e fontes vêm do `xp.css` na
implementação. O que vale neles são as proporções, a hierarquia, os estados e as
anotações.

O catálogo das 22 telas, com os endpoints que cada uma consome, está em
`../build-frontend.md`, seção "Catálogo de telas".
